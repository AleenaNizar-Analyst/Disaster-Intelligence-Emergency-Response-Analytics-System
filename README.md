# NASA EONET Disaster Intelligence Dashboard

An end-to-end data analytics project focused on analyzing global natural disaster and environmental event data using NASA's Earth Observatory Natural Event Tracker (EONET).

##  Project Overview

Natural disasters and environmental events generate large amounts of data that can be analyzed to identify patterns, trends, geographic distributions, and changes over time.

This project uses NASA EONET data to explore and analyze natural events and transform raw data into meaningful insights through data cleaning, analysis, and visualization.

The project demonstrates an end-to-end data analytics workflow using Python, SQL, Excel, and Power BI.

##  Objectives

- Analyze global natural disaster and environmental event data
- Identify patterns and trends across different event categories
- Explore the geographic distribution of natural events
- Analyze event occurrences over time
- Clean and transform raw data for analysis
- Generate meaningful insights from the dataset
- Present analytical findings through interactive visualizations

##  Data Source

The project uses data from NASA EONET (Earth Observatory Natural Event Tracker).

NASA EONET provides information about naturally occurring events around the world, including wildfires, storms, volcanoes, severe storms, and other environmental events.
